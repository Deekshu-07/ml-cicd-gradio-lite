# Drug Classification Dashboard

A browser-based drug classification demonstration using a Random Forest model exported to ONNX.

## Features

- Patient-feature input form
- ONNX Runtime Web inference in the browser
- Random Forest model trained on the Drug200 dataset
- Evaluation metrics and confusion matrix generated during training

## Disclaimer

This is an educational machine-learning demonstration, not a medical device. Predictions must not be used to make treatment decisions.
